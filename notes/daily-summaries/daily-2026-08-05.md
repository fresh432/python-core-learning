## RAG知识库流程

| 步骤 | 工具/概念 | 作用 |
|------|----------|------|
| 文档加载 | TextLoader | 读取本地文件为Document对象 |
| 语义切分 | RecursiveCharacterTextSplitter | 按优先级切分chunk，控制大小和重叠 |
| Embedding | OpenAIEmbeddings | 文本→向量，用于相似度计算 |
| 向量存储 | Chroma | 本地持久化向量库，支持增删查 |
| 检索 | similarity_search | 按向量相似度返回top-k片段 |
| 生成 | LLM + Prompt拼接 | 检索片段作为上下文，LLM基于事实回答 |
