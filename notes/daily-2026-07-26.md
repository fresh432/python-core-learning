## 回溯模板总结

```python
def backtrack(路径, 选择列表):
    if 满足结束条件:
        result.append(路径[:])  # 保存副本！
        return
    
    for 选择 in 选择列表:
        做选择（path.append）
        backtrack(新路径, 新选择列表)
        撤销选择（path.pop）  # 回溯
```
