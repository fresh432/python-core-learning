# LeetCode 969 煎饼排序

## 我的思路（50分钟）
- 前30分钟：整体思路：从大到小归位
  - 每次遍历找数组中最大值，同时保存下标
  - 把最大值翻到最前面（翻转 [0, i]），再根据当前未排序长度整体反转（翻转 [0, n-1]）
  - 每次反转操作把翻转长度加入 ans
  - 反转完未排序长度减一
  - 中间因数组不能同时进行截断和反转操作，花了10分钟调试
- 剪枝：最大值已在末尾则只对未排序长度减一、跳过其他操作；已在最前则直接反转未排序长度的数组
- 后来发现数字是 1~n 且不重复，又花10分钟把遍历找最大值改为用数组按下标定位

## 代码
```python
class Solution:
    def pancakeSort(self, arr: List[int]) -> List[int]:
        n = len(arr)
        ans = []
        while n > 1:
            for i, num in enumerate(arr):
                if num == n:
                    break
            if i == n - 1:          # 最大值已在末尾，归位完成
                arr = arr[:n - 1]
                n -= 1
                continue
            if i != 0:              # 最大值不在头部，先翻到头部
                tmp = arr[:i + 1]
                arr = tmp[::-1] + arr[i + 1:]
                ans.append(i + 1)
            arr = arr[::-1]         # 再翻到当前末尾
            arr = arr[:n - 1]
            ans.append(n)
            n -= 1
        return ans
```

## 关键
- 归位操作：最大值翻两次——先翻转 i+1 到头部，再翻转 n 到末尾（i 是最大值下标）
- 剪枝：i == n-1 时只缩短长度不翻转；i == 0 时跳过第一步翻转
- 数字是 1~n 排列：可用 pos = [0]*(n+1) 记录每个值的下标，找最大值 O(1) 代替遍历

## 教训
- 看到"煎饼排序/只允许前缀翻转" → 从大到小归位，每个数最多两次翻转
- 踩坑：切片反转 + 截断要分开写，同时操作容易出错
