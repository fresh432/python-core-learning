# LeetCode 714 买卖股票的最佳时机含手续费

## 我的思路（10分钟 + 10分钟优化）
- 10分钟：直接写出状态机 DP，比 309 简单，只要保存两种状态（持有/不持有），卖出时减去 fee 即可
- 又10分钟：看优化方案，发现每天状态只依赖前一天，可以用滚动数组压缩到 O(1) 空间
- 再10分钟：自己重写优化版

## 代码（初版）
```python
class Solution:
    def maxProfit(self, prices: List[int], fee: int) -> int:
        n = len(prices)
        dp = [[0] * n for _ in range(2)]
        dp[1][0] = -prices[0]
        
        for i in range(1, n):
            dp[1][i] = max(dp[0][i - 1] - prices[i], dp[1][i - 1])
            dp[0][i] = max(dp[0][i - 1], dp[1][i - 1] + prices[i] - fee)
        
        return max(dp[0][-1], dp[1][-1])
```

## 代码（优化版 — 滚动数组）
```python
class Solution:
    def maxProfit(self, prices: List[int], fee: int) -> int:
        p0, p1 = float('-inf'), 0  # p0: 持有, p1: 不持有
        
        for p in prices:
            new_p0 = max(p0, p1 - p)          # 买入：保持持有 / 从不持有买入
            new_p1 = max(p1, p0 + p - fee)    # 卖出：保持不持有 / 从持有卖出扣手续费
            p0, p1 = new_p0, new_p1
        
        return max(p0, p1)
```

## 关键
- 两种状态：
  - p0：持有股票（买入后的状态）
  - p1：不持有股票（卖出后的状态）
- 状态转移：
  - 买入：max(保持持有, 不持有 - 当前价格)
  - 卖出：max(保持不持有, 持有 + 当前价格 - fee)
- 手续费在卖出时扣除：p0 + p - fee
- 滚动数组优化：每天只依赖前一天，用两个变量代替二维数组，空间 O(1)

## 教训
- 状态机 DP 的通用优化：如果转移只依赖前一天，直接用滚动变量，空间从 O(n) 降到 O(1)
- 初始化：p0 = -inf 表示初始不可能持有股票，第一天循环后自动变为 -prices[0]
