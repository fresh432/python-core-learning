# LeetCode 693 交替位二进制数

## 我的思路（8分钟）
- 要求相邻两位的数字不能相同，用 3（二进制 11）与每个相邻位置做与运算
- 结果为 0（00）或 3（11）说明这两个相邻位相同，返回 False；全部比较完毕返回 True

## 代码
```python
class Solution:
    def hasAlternatingBits(self, n: int) -> bool:
        while n:
            if n & 3 == 0 or n & 3 == 3:
                return False
            n >>= 1
        return True
```

## 关键
- n & 3 取出最低两位：结果是 0（00）或 3（11）说明两位相同，返回 False
- 1（01）和 2（10）是合法情况，n 右移继续检查
- 循环到 n 为 0，说明所有相邻位都合法

## 教训
- 看到"相邻位是否交替/相同" → n & 3 取最低两位判断，右移遍历
- 位运算判断模板：要检查 k 个相邻位，就用 2^k - 1 做与运算
