# LeetCode 260 只出现一次的数字 III

## 我的思路（45分钟）
- 前5分钟：想到哈希表计数，但空间复杂度要求 O(1)，排除
- 中间10分钟：想到异或，但本题有两个只出现一次的数字，全员异或得到的是 a ^ b，不知道下一步怎么处理，卡住
- 后20分钟：看答案，核心洞察——利用异或结果的最低位1进行分组：
  - 全员异或得 xor_all = a ^ b
  - lowbit = xor_all & -xor_all：获取 xor_all 中最低位的1（利用负数的补码特性）
  - 根据 lowbit 将数组分成两组：该位为0的组和该位为1的组
  - 两组分别全员异或，得到两个只出现一次的数字
- 后10分钟：根据思路写出，通过

## 代码
```python
class Solution:
    def singleNumber(self, nums: List[int]) -> List[int]:
        xor_all = 0
        for num in nums:
            xor_all ^= num
        
        lowbit = xor_all & -xor_all  # 最低位的1
        
        ans = [0, 0]
        for num in nums:
            if (num & lowbit) == 0:
                ans[0] ^= num
            else:
                ans[1] ^= num
        
        return ans
```

## 关键
- 全员异或：xor_all = a ^ b（两个只出现一次的数异或结果）
- lowbit = xor_all & -xor_all：获取最低位的1
  - 原理：-xor_all 是 xor_all 的补码（取反+1），与原数相与得到最低位的1
- 分组依据：a 和 b 在 lowbit 这一位上必然不同（因为 xor_all 这一位是1）
- 分别异或：两组各自全员异或，出现两次的数会抵消，剩下只出现一次的那个

## 教训
- 看到"两个只出现一次的数字，其余出现两次" → 全员异或 + lowbit分组 + 分别异或
- lowbit 技巧：x & -x 获取最低位的1，经典位运算技巧
- 和 136/137 题对比：136 是一个数出现一次（全员异或），137 是一个数出现一次其余三次（位运算统计），260 是两个数各出现一次其余两次（异或+lowbit分组）
