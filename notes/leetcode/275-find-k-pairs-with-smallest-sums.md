# LeetCode 373 查找和最小的 K 对数字

## 我的思路（50分钟）
- 前20分钟：弄错题意，以为是按第一个下标排序、只需处理重复数字
- 发现是按两数之和从小到大排序，又花20分钟用双指针写，写到后面发现指针移动方向复杂、处理不下去
- 看答案10分钟：用堆存"两个数的和 + 对应下标"的三元组。之前想到过用堆，但以为要把所有元素入堆再吐出来会很耗时，就没做
- 思路：
  - 遍历 k 次，每次先吐出堆顶三元组、将下标对应数字加入 ans
  - 然后往堆中添加当前出堆下标后面的候选三元组：数组一的第 0 号元素组合（i+1, 0）在 j == 0 时入堆（防重），右邻（i, j+1）总是入堆

## 代码
```python
import heapq

class Solution:
    def kSmallestPairs(self, nums1: list[int], nums2: list[int], k: int) -> list[list[int]]:
        h = [(nums1[0] + nums2[0], 0, 0)]
        n1, n2 = len(nums1), len(nums2)
        ans = []
        for _ in range(k):
            _, i, j = heapq.heappop(h)
            ans.append([nums1[i], nums2[j]])
            if j + 1 < n2:                       # 右邻必入堆
                heapq.heappush(h, (nums1[i] + nums2[j + 1], i, j + 1))
            if j == 0 and i + 1 < n1:            # 列首邻入堆（仅 j==0 时，防重复）
                heapq.heappush(h, (nums1[i + 1] + nums2[0], i + 1, 0))
        return ans
```

## 关键
- 把 nums1 × nums2 的配对看成一个"行递增、列也递增"的虚拟矩阵，堆做的是多路归并
- 入堆规则：弹出 (i, j) 后，右邻 (i, j+1) 必入堆；列首邻 (i+1, 0) 只在 j == 0 时入堆——否则 (i+1, j+1) 等会被重复路径到达
- 堆中始终只有 O(k) 量级候选，弹 k 次，总复杂度 O(k log k)

## 教训
- 看到"两个升序数组的 K 个最小组合和" → 堆存（和, i, j) 三元组 + 防重入堆规则；双指针在这类"二维单调矩阵找 K 小"问题中方向单调性不成立
- 自己否决堆的理由（"全部入堆很耗时"）是误判，因为只要优化堆存储的数据量就还是可以用：堆只存候选边界，不是存全部 n×m 对
