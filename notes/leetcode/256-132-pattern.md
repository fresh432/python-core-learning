# LeetCode 456 132 模式

## 我的思路（50分钟）
- 前25分钟：想用栈存值，但用正序处理不了"后来的值比栈顶小"的情况
- 中间10分钟：改倒序——先定位 2 再去 2 的左边找 1 和 3，但这样写超时了
- 看提示：倒序 + 栈。倒着找时 2 和 3 是连着的，符合单调栈场景
- 又10分钟尝试但写绕了，看答案5分钟：倒序遍历，mid 变量维护"2"的值；当前元素 < mid 则返回 True；当前元素 > 栈顶则出栈（更新 mid）直到栈空或栈顶 ≥ 当前元素，然后当前元素入栈
- 理解后重新写了一遍：栈底存大数、栈顶存小数构成递减栈，只有外来数大于栈顶才触发 2 的更新，栈底是 2 的备选，保证 2 永远是仅次于当前最大数的

## 代码
```python
class Solution:
    def find132pattern(self, nums: list[int]) -> bool:
        stack = []
        mid = -inf  # 记录"2"的值
        for i in range(len(nums) - 1, -1, -1):
            if nums[i] < mid:      # 找到比2小的1
                return True
            while stack and stack[-1] < nums[i]:
                mid = max(stack.pop(), mid)  # 弹出的次大值成为新的2
            stack.append(nums[i])
        return False
```

## 关键
- 倒序遍历：当前元素是"1"的候选，栈中保存右边比它大的"3"候选
- 单调递减栈：栈底大、栈顶小；当前元素 > 栈顶时不断出栈，出栈的次大值更新 mid（即"2"）
- 判定：当前元素 < mid，说明存在 1 < 2 < 3 的结构，返回 True
- mid 维护的是"右边出现过的、仅次于最大值的次大值"

## 教训
- 看到"132 模式/找 i<j<k 且 nums[i]<nums[k]<nums[j]" → 倒序 + 单调递减栈 + mid 记录次大值
- 正序思路走不通时立刻换倒序——栈类模式匹配题，倒序往往让"3 和 2 相邻"
- 和 739 题对比：739 是正序单调栈找右边第一个更大值，456 是倒序单调栈维护次大值——方向选择由"要找的元素相对位置"决定
