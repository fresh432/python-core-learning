# LeetCode 44 通配符匹配

## 我的思路（40分钟）
- 前5分钟：想到和 10 题类似，写出大致框架
- 中间10分钟：观察与 10 题的差异——* 含义不同（通配符 * 匹配任意序列，正则 * 是前一个字符出现0-n次）
- 后25分钟：处理初始化和特殊情况，调试通过

## 代码
```python
class Solution:
    def isMatch(self, s: str, p: str) -> bool:
        n1, n2 = len(s), len(p)
        dp = [[False] * (n2 + 1) for _ in range(n1 + 1)]
        dp[0][0] = True
        
        # 初始化：s为空，p为 * 或 *** 时匹配
        for j in range(1, n2 + 1):
            dp[0][j] = dp[0][j - 1] and p[j - 1] == "*"
        
        for i in range(1, n1 + 1):
            for j in range(1, n2 + 1):
                if p[j - 1] == "*":
                    # * 匹配空串：dp[i][j-1]
                    # * 匹配一个或多个：dp[i-1][j]
                    dp[i][j] = dp[i][j - 1] or dp[i - 1][j]
                elif p[j - 1] == "?":
                    dp[i][j] = dp[i - 1][j - 1]
                else:
                    dp[i][j] = dp[i - 1][j - 1] and s[i - 1] == p[j - 1]
        
        return dp[n1][n2]
```

## 关键
- 通配符 *：匹配任意长度（包括0）的任意字符序列
  - 匹配空串：dp[i][j-1]
  - 匹配一个或多个：dp[i-1][j]
- ?：匹配任意单个字符
- 初始化：dp[0][j] 处理 p = "***" 匹配空串

## 和 10 题的对比
| 题目         | `*` 的含义     | `*` 的转移                          | 其他特殊字符         |
| ---------- | ----------- | -------------------------------- | -------------- |
| 10 正则      | 前一个字符出现0-n次 | `dp[i][j-2]` or `dp[i-1][j]`     | `.` 匹配任意字符     |
| **44 通配符** | **匹配任意序列**  | **`dp[i][j-1]` or `dp[i-1][j]`** | **`?` 匹配单个字符** |

## 教训
- 正则 * 和通配符 * 含义完全不同，不能混用
- 通配符 * 更简单：直接 or 两种选择（匹配空/匹配一个+）
- 看到"通配符匹配" → 先确认 * 的定义，再写转移方程
