# LeetCode 152 乘积最大子数组

## 我的思路（45分钟）
- 前15分钟：试图用53题类似的方法，但忽略了负数的影响——两个负数相乘会变成正数，所以只维护最大值不够
- 中间20分钟：想到需要同时维护最大值和最小值，遇到负数时两者交换（负数×最小值可能变成最大值），但维护逻辑没写好
- 后10分钟：看答案，理解了交换和更新的顺序，自己写了一遍

## 代码
```python
class Solution:
    def maxProduct(self, nums: List[int]) -> int:
        ans, imax, imin = nums[0], 1, 1
        
        for i in range(len(nums)):
            if nums[i] < 0:
                # 负数：最大值和最小值交换
                temp = imax
                imax = imin
                imin = temp
            
            imax = max(imax * nums[i], nums[i])
            imin = min(imin * nums[i], nums[i])
            ans = max(ans, imax)
        
        return ans
```

## 关键
- 同时维护两个状态：
  - imax：以当前元素结尾的最大乘积
  - imin：以当前元素结尾的最小乘积
- 负数交换：nums[i] < 0 时，imax 和 imin 交换（因为负数×最小值 = 最大值）
- 更新顺序：先交换，再分别用 max/min 更新

## 教训
- 看到"乘积最大子数组" → 同时维护最大值和最小值，因为负数会让最小值变最大值
- 和 53 题对比：53 是求和（只维护最大值即可），152 是求积（必须同时维护最大和最小）
