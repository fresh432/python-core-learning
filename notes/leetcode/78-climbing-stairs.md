# LeetCode 70 爬楼梯

## 我的思路（20分钟）
1. 前10分钟：想用递归写，结果超时——纯递归有大量重复计算
2. 后10分钟：看答案理解——动态规划，本质就是斐波那契数列：dp[i] = dp[i-1] + dp[i-2]

## 代码
```python
class Solution:
    def climbStairs(self, n: int) -> int:
        if n <= 2:
            return n
        dp = [0] * (n + 1)
        dp[1], dp[2] = 1, 2
        for i in range(3, n + 1):
            dp[i] = dp[i - 1] + dp[i - 2]
        return dp[n]
```

## 关键
- 状态定义：dp[i] = 爬到第 i 阶的方法数
- 状态转移：dp[i] = dp[i-1] + dp[i-2]
  - 最后一步跨1阶：dp[i-1] 种
  - 最后一步跨2阶：dp[i-2] 种
- 初始状态：dp[1] = 1，dp[2] = 2

## 教训
- 递归超时 → 立刻想到记忆化搜索或动态规划
- 看到"方法数/方案数" + 每一步有固定选择（1或2）→ 斐波那契/DP
- 空间可优化：只用两个变量滚动，O(1) 空间
