# LeetCode 454 四数相加 II

## 我的思路（20分钟）
- 前10分钟：想存三个数组所有和的哈希表，再用最后一个数组查找——O(n³) 超时
- 苦想10分钟：改为只存前两个数组的和进哈希表（值为出现次数，这样不会漏掉值重复但组合不同的结果），后两个数组求和取反后查找——两次遍历都是 O(n²)，通过

## 代码
```python
class Solution:
    def fourSumCount(self, nums1: List[int], nums2: List[int],
                     nums3: List[int], nums4: List[int]) -> int:
        hash_map = defaultdict(int)
        n = len(nums1)
        ans = 0
        for i in range(n):
            for j in range(n):
                hash_map[nums1[i] + nums2[j]] += 1
        for i in range(n):
            for j in range(n):
                target = -(nums3[i] + nums4[j])
                if target in hash_map:
                    ans += hash_map[target]
        return ans
```

## 关键
- 分组哈希：nums1+nums2 的和存为哈希（值 = 出现次数），nums3+nums4 求和后查其相反数
- 哈希值必须是次数而非布尔：和相同但来自不同 (i,j) 组合，每个组合都要计数
- O(n²) 时间、O(n²) 空间

## 教训
- 看到"四个数组凑零计数/四数之和计数" → 分两组哈希，A+B 存次数、C+D 查相反数
