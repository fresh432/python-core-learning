# LeetCode 115 不同的子序列

3. 后25分钟：重新写状态转移方程，调试通过

## 代码
```python
class Solution:
    def numDistinct(self, s: str, t: str) -> int:
        n1, n2 = len(s), len(t)
        dp = [[0] * (n2 + 1) for _ in range(n1 + 1)]
        
        # 关键初始化：t为空串时，s有1种匹配方式（全删除）
        for i in range(n1 + 1):
            dp[i][0] = 1
        
        for i in range(1, n1 + 1):
            for j in range(1, n2 + 1):
                if s[i - 1] == t[j - 1] and i >= j:
                    # 匹配：用s[i-1]匹配t[j-1] + 不用s[i-1]匹配t[j-1]
                    dp[i][j] = dp[i - 1][j - 1] + dp[i - 1][j]
                else:
                    dp[i][j] = dp[i - 1][j]
        
        return dp[n1][n2]
```

## 关键
- 状态定义：dp[i][j] = s[0:i] 中 t[0:j] 出现的子序列个数
- 初始化：dp[i][0] = 1（空串 t 是任何 s 的子序列，只有1种方式——全删）
- 状态转移：
  - 字符相等：dp[i][j] = dp[i-1][j-1] + dp[i-1][j]
    - 用 s[i-1] 匹配 t[j-1]：dp[i-1][j-1]
    - 不用 s[i-1] 匹配：dp[i-1][j]
  - 字符不等：dp[i][j] = dp[i-1][j]（只能不用）

## 教训
- 子序列计数问题的初始化容易错：dp[i][0] = 1 不是 0
- 看到"求子序列的个数/方案数" → dp[i][j] 计数，相等时累加两种选择
- 和 1143 题（LCS）对比：

| 题目            | dp 含义    | 相等时          |
| ------------- | -------- | ------------ |
| 1143 LCS      | 最长长度     | `左上 + 1`     |
| **115 不同子序列** | **出现次数** | **`左上 + 上`** |
