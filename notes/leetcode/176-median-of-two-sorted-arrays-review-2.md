# LeetCode 4 寻找两个正序数组的中位数（复习）

## 我的思路（30分钟）
- 前20分钟：想到短数组二分切分，但忘了怎么收缩边界和切分条件
- 后5分钟：看了之前写的答案，想起来：
  - 保证 nums1 是较短数组
  - 边界设为短数组的左右两端 imin=0, imax=m
  - i = (imin + imax) // 2，j = mid - i
  - 比较 nums1[i] 和 nums2[j-1]、nums1[i-1] 和 nums2[j] 来收缩边界
- 后5分钟：重写了一遍，通过

## 复习要点
- 只在较短数组上二分，时间 O(log(min(m,n)))
- mid = (m + n + 1) // 2，左边部分总元素数
- 切分正确条件：nums1[i-1] <= nums2[j] 且 nums2[j-1] <= nums1[i]
- 边界处理：i==0、i==m、j==0、j==n 四种边缘情况
