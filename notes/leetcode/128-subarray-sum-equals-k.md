# LeetCode 560 和为 K 的子数组

## 我的思路（70分钟）

- 中间40分钟：看答案，理解了前缀和 + 哈希表——sum[0:j] = s，找之前有多少个前缀和等于 s - k
- 后10分钟：自己写了一遍

## 代码
```python
from collections import defaultdict

class Solution:
    def subarraySum(self, nums: List[int], k: int) -> int:
        cnt = defaultdict(int)
        cnt[0] = 1  # 前缀和为0出现1次（空数组）
        ans = s = 0
        
        for x in nums:
            s += x
            # 之前有多少个前缀和等于 s - k，就有多少个子数组和为 k
            ans += cnt[s - k]
            cnt[s] += 1
        
        return ans
```

## 关键
- 前缀和：s = nums[0] 到 nums[i] 的累加和
- 子数组 nums[j+1:i] 的和 = s - prefix[j]，若等于 k，则 prefix[j] = s - k
- cnt[s - k]：表示之前有多少个前缀和等于 s - k，即有多少个以当前位置结尾的子数组和为 k
- cnt[0] = 1：处理从数组开头开始的子数组（prefix[-1] = 0）

## 教训
- 看到"子数组和为 k" → 前缀和 + 哈希表，O(n)
- 含负数的数组不能用滑动窗口，因为窗口和不具有单调性，无法通过收缩左边界来调节
- cnt[0] = 1 是初始化关键，否则漏算从索引 0 开始的子数组
- 和 3 题对比：3 是滑动窗口（无重复约束），560 是前缀和（求和约束）
