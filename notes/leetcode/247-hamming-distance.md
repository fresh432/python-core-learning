# LeetCode 461 汉明距离

## 我的思路（7分钟）
- 先将两个数字异或，再计数 1 的个数
- 一开始把异或逻辑搞反了——以为是"相同为 1 不同为 0"，还想对结果取反再计数；重新看了眼异或定义才想起来是"不同为 1 相同为 0"，那就简单了：异或后直接 z & (z-1) 计数

## 代码
```python
class Solution:
    def hammingDistance(self, x: int, y: int) -> int:
        z = x ^ y
        ans = 0
        while z:
            z &= (z - 1)
            ans += 1
        return ans
```

## 关键
- 异或：不同为 1、相同为 0 → x ^ y 的 1 恰好就是两数不同的位
- 数 1 个数：z & (z-1) 循环

## 教训
- 看到"两数对应位不同的个数/汉明距离" → 异或 + Brian Kernighan 计数
- 踩坑：异或定义记反了（相同为 1 是 XNOR）。基础位运算定义要记牢：异或=不同为 1
- 和 191 题对比：191 数一个数的 1，461 先异或再数——同一技巧的串联
