# LeetCode 342 4 的幂

## 我的思路（2分钟）
- 在判断 2 的幂的基础上，再保证该数对 3 取模等于 1
- 原因：由二项式定理，(3+1)ⁿ 展开后只有 4 的幂对 3 取模余 1（2 的幂中对 3 余 1 的只有 4 的幂）

## 代码
```python
class Solution:
    def isPowerOfFour(self, n: int) -> bool:
        if n > 0 and n & (n - 1) == 0 and n % 3 == 1:
            return True
        return False
```

## 关键
- 先满足 2 的幂（n > 0 且 n & (n-1) == 0），再用 n % 3 == 1 筛出 4 的幂
- 数学依据：4ⁿ = (3+1)ⁿ ≡ 1 (mod 3)，而 2·4ⁿ ≡ 2 (mod 3)

## 教训
- 看到"判断 4 的幂" → 2 的幂判定 + n % 3 == 1
- 和 231 题对比：231 是 n & (n-1)，342 再加一层模运算筛选——"幂的幂"问题用模运算区分
