# LeetCode 231 2 的幂

## 我的思路（2分钟）
- 二进制中尾部每加一个 0 表示数字乘一个 2，所以 2 的幂应该是只有最高位为 1、其余位全为 0
- 只需判断 n & (n-1) 结果是否为 0，同时排除 n = 0 的情况

## 代码
```python
class Solution:
    def isPowerOfTwo(self, n: int) -> bool:
        if n & (n - 1) == 0 and n > 0:
            return True
        return False
```

## 关键
- 2 的幂的二进制特征：只有一个 1（最高位）
- n & (n-1) == 0 表示二进制中只有一个 1

## 教训
- 看到"判断是否为 2 的幂" → n & (n-1) == 0 且 n > 0
- 和 191 题对比：同一技巧的两个应用——191 用它循环数 1 的个数，231 用它判断 1 的个数是否为 1
