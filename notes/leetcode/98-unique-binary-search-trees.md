# LeetCode 96 不同的二叉搜索树

## 我的思路（35分钟）
- 前20分钟：卡在 n 和 n-1 之间的状态关联，试图找线性递推关系，始终想不通
- 中间5分钟：看答案，发现核心洞察——每个 dp[n] 是由 n 个节点中每个节点轮流当根节点时的种类之和
- 后10分钟：豁然开朗，写出代码

## 代码
```python
class Solution:
    def numTrees(self, n: int) -> int:
        dp = [0] * (n + 1)
        dp[0] = 1  # 空树算1种
        dp[1] = 1  # 单节点树
        
        for i in range(2, n + 1):
            for j in range(i):
                # j 个节点构成左子树，i-j-1 个节点构成右子树
                dp[i] += dp[j] * dp[i - j - 1]
        
        return dp[-1]
```

## 关键
- 状态定义：dp[i] = i 个节点能组成的不同二叉搜索树的种数
- 状态转移：dp[i] += dp[j] * dp[i-j-1]
  - 枚举每个节点 j+1 作为根节点（j 从 0 到 i-1）
  - 左子树有 j 个节点 → dp[j] 种
  - 右子树有 i-j-1 个节点 → dp[i-j-1] 种
  - 左右独立，乘法原理相乘
- 初始化：dp[0] = 1（空树是一种合法结构，作为乘法单位元），dp[1] = 1
- 本质：这是卡特兰数（Catalan Number）的经典递推式

## 教训
- 看到"BST 的种数/结构数" → 卡特兰数 DP，核心思想是"每个节点轮流当根"
- dp[0] = 1 不是 0，空树作为乘法单位元是推导正确的关键
- 不要试图找 dp[n] 和 dp[n-1] 的直接线性关系，BST 计数天然是"枚举根节点"的卷积结构
- 和 70 题（爬楼梯）对比：爬楼梯是 dp[i] = dp[i-1] + dp[i-2] 的线性递推，96 题是 dp[i] = Σ dp[j] * dp[i-j-1] 的卷积递推
