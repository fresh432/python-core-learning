# LeetCode 470 用 Rand7 实现 Rand10

## 我的思路（40分钟）
- 前20分钟：让 rand7 调用 10 次累加，得到 7~70 再对 7 整除返回——没通过；想到是因为上界只有全部调用为 7 才能获得，导致分布不均
- 看提示提到"拒绝采样"：改成调用 10 次累加，结果为 7~10 时重新调用，再对 10 取模（为 0 则返回 10）——通过，但均分原理不清楚，按直觉写的
- 又10分钟看答案优化：一个 rand7 负责随机 1~7，另一个 (rand7-1)×7 负责 7 的倍数，相加得 1~49 的均分随机数；拒绝 40 以上的情况，得到 1~40 均分，对 10 取模加一返回

## 代码
```python
class Solution:
    def rand10(self):
        ans = 0
        while ans <= 10:
            ans = 0
            for _ in range(10):
                ans += rand7()
            ans = ans % 10
        return ans if ans != 0 else 10
```

## 代码（标准解）
```python
class Solution:
    def rand10(self):
        while True:
            ans = (rand7() - 1) * 7 + rand7()
            if ans <= 40:
                return ans % 10 + 1
```

## 关键
- (rand7()-1)×7 提供 0、7、14…42 的"高位基底"，+ rand7() 填充个位，7×7 = 49 种组合一一映射到 1~49，概率均等
- 拒绝采样：1~49 中只保留 1~40（10 的整数倍个），>40 的 9 个数拒绝重 roll，40/49 的接受率
- 取模映射：1~40 对 10 取模加一，恰好均分映射到 1~10

## 教训
- 看到"用 randX 实现 randY" → 拒绝采样：先构造比目标大的均分空间（X 的幂次），截断到 Y 的整数倍，再取模
- 自己第一版累加 10 次的不均根源：和的分布是中间高两头低的钟形，不是均分
- 公式要记牢：(randX()-1)×X + randX() 生成 1~X² 均分
