# LeetCode 31 下一个排列

## 代码
```python
class Solution:
    def nextPermutation(self, nums: List[int]) -> None:
        n = len(nums)
        i = n - 2
        
        # Step 1: 从后往前找第一个下降点
        while i >= 0 and nums[i] >= nums[i + 1]:
            i -= 1
        
        if i >= 0:
            # Step 2: 从后往前找第一个比 nums[i] 大的数
            j = n - 1
            while nums[j] <= nums[i]:
                j -= 1
            nums[i], nums[j] = nums[j], nums[i]
        
        # Step 3: 反转 i 后面的部分（从降序变升序）
        left, right = i + 1, n - 1
        while left < right:
            nums[left], nums[right] = nums[right], nums[left]
            left += 1
            right -= 1
```

## 关键
- 三步固定套路：
  1. 找下降点：从后往前找第一个 nums[i] < nums[i+1]，说明 i 位置可以变大
  2. 找替换数：从后往前找第一个 nums[j] > nums[i]，交换后得到下一个更大的排列
  3. 反转后缀：i 后面的部分原本是从大到小，反转后变成从小到大，得到"下一个"排列
- 边界：i < 0 说明整个数组是降序（最大排列），直接反转成升序（最小排列）

## 教训
- 看到"下一个排列" → 三步走：找下降点 → 找替换数 → 反转后缀
- 为什么反转后缀：交换后 i 后面的部分仍然保持降序，反转后才是升序，即该后缀的最小排列
