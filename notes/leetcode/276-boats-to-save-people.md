# LeetCode 881 救生艇

## 我的思路（37分钟）
- 前20分钟：想过先排序，拿最大的不断填充更小的来填满 limit 再计数，感觉指针做不到；又想到零钱兑换那样换更优组合，但明显不能用 DP
- 看提示：先排序、大和小配对。花15分钟按此尝试没通过——我以为要把 limit 填满才能得到最小船数
- 再看提示和题目：一艘船最多坐两个人。前面的想法一直是"怎么塞最多人上一艘船"。改 2 分钟通过
- 正确思路：
  - 排序后左右指针指向边界，最重 + 最轻 ≤ limit 则双指针前进、计数 +1 ，否则只有重指针前进。
  - 为什么最重带最轻可行：带最合适的和带最小的都是同样用一艘船，最合适的那个最佳匹配本来就是最大的，而最大的已经匹配出去了，剩下都 ≤ 最大，最合适的一样能正常匹配其他人，所以直接匹配最小的没问题且更省事

## 代码
```python
class Solution:
    def numRescueBoats(self, people: list[int], limit: int) -> int:
        people.sort()
        ans = 0
        i, j = 0, len(people) - 1
        while i <= j:
            if people[j] + people[i] <= limit:   # 最重能捎上最轻
                i += 1
            ans += 1                              # 每轮必用一条船（最重的人）
            j -= 1
        return ans
```

## 关键
- 排序 + 双指针；每轮最重的人必上船（j 必走），能带最轻就捎上（i++）
- 贪心正确性（交换论证）：假设最优解中最重 j 配了某个 x 而非最轻 i，把 x 换成 i 不增加船数；因为 i ≤ x，i 能去的地方 x 不一定能去，但反过来把 x 留给后面的人，x ≤ limit - j' 对后面更轻的 j' 更容易满足
- O(n log n)
