# LeetCode 309 最佳买卖股票时机含冷冻期

## 我的思路（40分钟）
- 前15分钟：理解题意，想到用状态机 DP，每天有三种状态（买入、卖出、冷冻期），但初始化时忽略了第一天需要先执行买入操作，卡了10分钟调试
- 中间5分钟：参考别人思路，确认三种状态之间的转移关系
- 后10分钟：代码实现并通过

## 代码
```python
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        n = len(prices)
        dp = [[0] * n for _ in range(3)]
        dp[1][0] = -prices[0]  # 第一天买入
        
        for i in range(1, n):
            # 买入状态：昨天冷冻期今天买入 / 昨天就持有
            dp[1][i] = max(dp[0][i - 1] - prices[i], dp[1][i - 1])
            # 卖出状态：昨天持有今天卖出 / 昨天已卖出
            dp[2][i] = max(dp[1][i - 1] + prices[i], dp[2][i - 1])
            # 冷冻期：昨天刚卖出进入冷冻 / 保持冷冻
            dp[0][i] = max(dp[2][i - 1], dp[0][i - 1])
        
        return max(dp[1][-1], dp[2][-1], dp[0][-1])
```

## 关键
- 三种状态：
  - dp[0][i]：第 i 天处于冷冻期（前一天刚卖出，今天不能买）
  - dp[1][i]：第 i 天持有股票
  - dp[2][i]：第 i 天不持有股票且不在冷冻期（可自由交易）
- 状态转移：
  - 持有 ← 冷冻期买入 / 保持持有
  - 卖出 ← 持有卖出 / 保持卖出
  - 冷冻期 ← 刚卖出进入冷冻 / 保持冷冻状态
- 初始化：dp[1][0] = -prices[0]（第一天买入，利润为负）

## 教训
- 看到"股票交易 + 冷冻期/限制" → 状态机 DP，先画状态转移图
- 初始化陷阱：第一天必须考虑"买入"操作，利润为 -prices[0] 不是 0
- 状态机 DP 的核心：用多个 dp 数组表示不同状态，转移时只从合法的前置状态转移
- 和 714 题对比：309 是三种状态（多了冷冻期），714 是两种状态（只有持有/不持有）
