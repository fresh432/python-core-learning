# LeetCode 319 灯泡开关

## 我的思路（30分钟）
- 前5分钟：双层循环暴力模拟，超时
- 中间15分钟：想到用切换次数的规律——每个位置的切换次数等于它的因子个数，而因子成对出现，只有当位置是完全平方数时才有奇数个因子，即只有平方数位置最后为 1。写了两循环版（改位 + 统计），又优化成一遍循环（开方为整数则计数），还是超时
- 最后5分钟：终于想明白——统计 0~n 中完全平方数的个数，直接看 n 开方后的整数部分即可，一行通过

## 代码
```python
class Solution:
    def bulbSwitch(self, n: int) -> int:
        return int(n ** (1/2))
```

## 关键
- 第 i 个灯泡被切换的次数 = i 的因子个数（第 k 轮切换所有 k 的倍数）
- 因子成对出现（d 与 n/d），仅完全平方数有奇数个因子（√n 自身配对）→ 只有平方数位置最后亮着
- 0~n 中完全平方数个数 = ⌊√n⌋

## 教训
- 看到"开关/翻转类模拟" → 先想因子个数与奇偶性，最终化简为数学公式
- 踩坑路径：暴力模拟 → 找规律减半 → 再化简到 O(1)。模拟题的多余循环都是没化简到底的信号
