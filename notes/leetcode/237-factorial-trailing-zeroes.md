# LeetCode 172 阶乘后的零

## 我的思路（15分钟）
- 观察规律：n 中含因子 5 就会出现 0。最初想法是遍历每个数、遇到 5 的倍数就 ans+1，但处理不了 125 这种含多个 5 的数
- 看提示要求对数时间复杂度，想到直接在 n 上数因子 5：当前 n 整除 5 的商加入 ans，再 n //= 5 重复，直到 n 为 0

## 代码
```python
class Solution:
    def trailingZeroes(self, n: int) -> int:
        ans = 0
        while n:
            ans += n // 5
            n //= 5
        return ans
```

## 关键
- 尾随 0 由因子 2 × 5 产生，因子 2 永远比 5 多，只需数因子 5
- n//5 得到"5 的倍数的个数"，n//25 得到"含两个 5 的额外计数"……循环 n //= 5 天然覆盖

## 教训
- 看到"阶乘尾随 0 的个数" → 数因子 5，n //= 5 循环累加
- 踩坑：遍历每个数的思路处理不了 5 的幂（如 125 = 5³ 贡献三个 5），直接对 n 反复除 5 才是正解
