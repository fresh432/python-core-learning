# LeetCode 198 打家劫舍

## 我的思路（25分钟）
- 前10分钟：没有思路
- 中间10分钟：看了提示意识到和 70 题类似——当前状态由前两个状态决定
- 后5分钟：写出代码，简单调试通过

## 代码
```python
class Solution:
    def rob(self, nums: List[int]) -> int:
        n = len(nums)
        if n < 2:
            return nums[0]
        if n <= 2:
            return max(nums[0], nums[1])
        
        f = [0] * n
        f[0] = nums[0]
        f[1] = max(nums[1], nums[0])
        
        for i in range(2, n):
            f[i] = max(f[i - 1], f[i - 2] + nums[i])
        
        return f[n - 1]
```

## 关键
- 状态定义：f[i] = 偷到第 i 家时的最大金额
- 状态转移：f[i] = max(f[i-1], f[i-2] + nums[i])
  - 不偷第 i 家：f[i-1]
  - 偷第 i 家：f[i-2] + nums[i]（不能偷第 i-1 家）
- 初始状态：f[0] = nums[0]，f[1] = max(nums[0], nums[1])

## 和 70 题的对比
| 题目           | 状态转移                                     | 核心区别               |
| ------------ | ---------------------------------------- | ------------------ |
| 70 爬楼梯       | `dp[i] = dp[i-1] + dp[i-2]`              | **求方法数**，两种选择累加    |
| **198 打家劫舍** | **`f[i] = max(f[i-1], f[i-2]+nums[i])`** | **求最大值**，两种选择取 max |

## 教训
- 看到"相邻不能同时选/偷" → 动态规划，状态转移取 max
- 70 题是"方法数"问题（累加），198 是"最值"问题（取 max）——转移方程不同
- DP 的核心三步：定义状态 → 找转移方程 → 确定初始状态
