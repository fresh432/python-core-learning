# LeetCode 120 三角形最小路径和

## 我的思路（50分钟）
- 前30分钟：思路被自己想复杂了——试图构建一个"梯形"的 dp 数组来对应三角形结构，自底向上的方向也弄反了，想的是 dp[i][j] 继承自"上面那个"和"上面右边那个"的最小值，然后处理边界（边上的元素只能继承上面），从上往下遍历，越写越复杂
- 中间10分钟：看答案，发现根本不需要这么复杂——自底向上，一维数组即可，每个位置只需要关心下一行相邻两个位置的最小值
- 后10分钟：理解后自己重写，代码非常简洁

## 代码
```python
class Solution:
    def minimumTotal(self, triangle: List[List[int]]) -> int:
        n = len(triangle)
        dp = [0] * (n + 1)  # 多一位，最后一行下面全为0
        
        for i in range(n, 0, -1):      # 自底向上
            for j in range(i):
                dp[j] = min(dp[j], dp[j + 1]) + triangle[i - 1][j]
        
        return dp[0]
```

## 关键
- 自底向上：从三角形最后一行往上推，避免处理顶部到底部的多条路径选择
- 状态定义：dp[j] = 从当前行第 j 个元素出发，到达底部的最小路径和
- 状态转移：dp[j] = min(dp[j], dp[j+1]) + triangle[i-1][j]
  - 当前元素可以走到下一行的 j 或 j+1，取两者最小值
  - 加上当前元素的值
- 一维数组优化：自底向上时，下一行的 dp 值就是上一行需要的值，原地更新即可
- 初始化：dp 数组长度 n+1，最后一行下面全为 0，天然作为边界

## 教训
- 看到"三角形/金字塔最小路径" → 自底向上 + 一维 DP，不要从上往下
- 从上往下的问题：顶部到底部有多条路径，需要同时维护很多状态；自底向上每个位置只需要下一行的信息
- 一维优化的关键：自底向上时，dp[j] 和 dp[j+1] 正好是下一行对应位置的值，更新不会互相干扰（因为用的是旧值）
