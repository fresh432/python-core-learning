# LeetCode 122 买卖股票的最佳时机 II

## 我的思路（40分钟）
- 前30分钟：思维定势严重。因为之前做过带冷冻期/手续费的股票DP（309、714），大脑默认进入"状态机模式"，试图用数组保存每天的多状态来实现"跨多天持有"的复杂逻辑，越想越绕，完全没写出来
- 后5分钟：看答案，核心洞察——把跨多天的连续上涨拆成每天的小买卖。例如第1天买第3天卖，利润 = (p2-p1) + (p3-p2)，数学上等价于相邻两天正差值之和
- 后5分钟：根据这个等价拆分思路，直接写出贪心代码

## 代码
```python
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        n = len(prices)
        ans = 0
        for i in range(1, n):
            if prices[i] > prices[i - 1]:
                ans += prices[i] - prices[i - 1]
        return ans
```

## 关键
- 贪心：将所有上升段的利润累加
- 跨多天买卖的等价拆分：持有3天获得的利润 = 相邻两天正差值之和
- 代码极简：只要今天比昨天高，就把差值加入答案

## 教训
- 看到"可以多次交易" → 先想最简单的情况：每天能交易吗？利润怎么算？不要一上来就套高级模型
- 思维陷阱：不要因为做过复杂的股票DP（状态机）就默认每道股票题都要上DP。先分析约束条件：本题不限制交易次数且无手续费，贪心即可
- 复杂问题先尝试等价转换/数学拆分，再考虑是否需要DP
