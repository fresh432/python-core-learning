# LeetCode 1209 删除字符串中的所有相邻重复项 II

## 我的思路（35分钟）
- 前25分钟：用栈保存（字符，连续次数）元组，连续次数达 k 时弹出 k-1 个，再弹出一个重新入栈重复操作。边界调试了一会，通过但复杂
- 后10分钟：看答案，原来重复字符不用真的逐个入栈——栈顶与当前字符相等则把栈顶次数 +1，不等则连同 1 入栈，然后判断栈顶次数是否达 k 弹出。返回时每个字符乘上次数拼接。按这个方法写了一遍

## 代码（标准解）
```python
class Solution:
    def removeDuplicates(self, s: str, k: int) -> str:
        stack = [[' ', 0]]  # 哨兵，免去空栈判断

        for ch in s:
            if stack[-1][0] != ch:
                stack.append([ch, 1])
            else:
                stack[-1][1] += 1

            if stack[-1][1] == k:
                stack.pop()

        return ''.join(ch * cnt for ch, cnt in stack)
```

## 关键
- 栈存 [字符, 连续次数]，重复字符不逐个入栈，只给栈顶次数 +1
- 栈顶次数达 k 直接弹出，一次搞定
- 哨兵元素 [' ', 0] 免去空栈判断；返回时 ' ' * 0 不影响结果
- 拼接：''.join(ch * cnt for ch, cnt in stack)

## 教训
- 看到"删除 k 个相邻重复项" → 栈存 (字符, 次数)，达 k 弹出
- 和 1047 题对比：1047 是 k=2 的特例（栈顶相等即弹），1209 是通用计数版
- 教训：连续的重复元素用"计数"而不是"逐个入栈"，逻辑简洁得多
