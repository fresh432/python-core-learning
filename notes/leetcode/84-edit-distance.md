# LeetCode 72 编辑距离

## 我的思路（35分钟）
1. 前15分钟：想用找最大公共子序列的方法间接求最小操作数，写到后面发现实现不了
2. 后20分钟：看答案理解——直接定义 dp[i][j] 为将 word1[0:i] 转成 word2[0:j] 的最小操作数。动手画矩阵后清晰很多

## 代码
```python
class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        n1, n2 = len(word1), len(word2)
        dp = [[0] * (n2 + 1) for _ in range(n1 + 1)]
        
        # 初始化：一个空串转成另一个串，只能不断插入
        for j in range(1, n2 + 1):
            dp[0][j] = dp[0][j-1] + 1
        for i in range(1, n1 + 1):
            dp[i][0] = dp[i-1][0] + 1
        
        for i in range(1, n1 + 1):
            for j in range(1, n2 + 1):
                if word1[i-1] == word2[j-1]:
                    dp[i][j] = dp[i-1][j-1]      # 相同，无需操作
                else:
                    dp[i][j] = min(
                        dp[i][j-1],      # 插入：word1插入word2[j-1]
                        dp[i-1][j],      # 删除：删除word1[i-1]
                        dp[i-1][j-1]     # 替换：把word1[i-1]替换成word2[j-1]
                    ) + 1
        
        return dp[n1][n2]
```

## 关键
- 状态定义：dp[i][j] = word1[0:i] → word2[0:j] 的最小操作数
- 状态转移：
  - 字符相等：dp[i][j] = dp[i-1][j-1]（不用操作）
  - 字符不等：min(插入, 删除, 替换) + 1
- 初始化：第一行/列表示空串转换，只能插入/删除

## 教训
- 看到"字符串转换/编辑距离" → 二维 DP，直接定义最小操作数，不要绕弯找公共子序列
- 画矩阵是理解二维 DP 的必备技能，手动推导几个格子就能发现规律
- 和 1143 题（LCS）对比：

| 题目          | dp 含义     | 不等时                     |
| ----------- | --------- | ----------------------- |
| 1143 LCS    | 最长公共子序列长度 | `max(左, 上)`             |
| **72 编辑距离** | **最小操作数** | **`min(左, 上, 左上) + 1`** |
