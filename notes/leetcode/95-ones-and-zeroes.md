# LeetCode 474 一和零

## 我的思路（60分钟）
- 前10分钟：直觉判断是 0-1 背包问题，但卡在两个限制条件（0 的个数和 1 的个数）如何同时维护，不知道状态该怎么定义
- 中间35分钟：看答案，理解了二维费用背包的概念——dp[j][k] 同时记录两种资源的消耗
- 后15分钟：写出代码，对每个字符串先统计 c0 和 c1，然后在内层两个维度上倒序更新

## 代码
```python
class Solution:
    def findMaxForm(self, strs: List[str], m: int, n: int) -> int:
        dp = [[0] * (n + 1) for _ in range(m + 1)]
        
        for s in strs:
            c0 = s.count('0')
            c1 = len(s) - c0
            
            for j in range(m, c0 - 1, -1):
                for k in range(n, c1 - 1, -1):
                    dp[j][k] = max(dp[j][k], dp[j - c0][k - c1] + 1)
        
        return dp[m][n]
```

## 关键
- 状态定义：dp[j][k] = 使用 j 个 0 和 k 个 1 时，能选取的最多字符串个数
- 状态转移：dp[j][k] = max(dp[j][k], dp[j-c0][k-c1] + 1)
  - 不选当前字符串：保持 dp[j][k]
  - 选当前字符串：dp[j-c0][k-c1] + 1（消耗对应资源，数量 +1）
- 两个维度都倒序：range(m, c0-1, -1) 和 range(n, c1-1, -1)，确保每个字符串只选一次（0-1 背包）
- 预处理：每个字符串的 c0 和 c1 只需计算一次

## 教训
- 看到"两种资源限制 + 每个物品只能选一次" → 二维费用 0-1 背包
- 从 0-1 背包的一维 dp[j] 扩展到二维 dp[j][k]，核心逻辑完全一致，只是多了一层循环
- 和 416/494 题对比：416/494 是单维度的 0-1 背包（判定/计数），474 是二维费用的 0-1 背包最值
