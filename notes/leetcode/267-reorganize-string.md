# LeetCode 767 重构字符串

## 我的思路（40分钟）
- 前35分钟：先对所有字符计数，用最大计数与 ⌈n/2⌉ 比较判断可行性
  - 再用大顶堆维护计数，每次取两个出现次数最多的字符轮流填入 ans，一个用完再补一个。
  - 卡点：aabbcc 这种所有字符次数相同的情况，前面填成 abab，接下来填 c 必然相邻，失败
- 看答案5分钟：先把出现次数最多的元素放满偶数位（其计数 ≤ 偶数位个数，所以不会相邻重复），其余字符按频次顺序填充剩余奇数位。顺便把大顶堆改为哈希表排序维护，填充改为奇偶位填充法，通过

## 代码
```python
from collections import Counter

class Solution:
    def reorganizeString(self, s: str) -> str:
        n = len(s)
        counts = Counter(s).most_common()   # 按频次降序
        max_count = counts[0][1]
        if max_count > (n + 1) // 2:        # 可行性判断
            return ""

        ans = [""] * n
        i = 0
        for ch, cnt in counts:
            for _ in range(cnt):
                ans[i] = ch
                i += 2                      # 先填偶数位
                if i >= n:                  # 偶数位放满，转到奇数位
                    i = 1
        return "".join(ans)
```

## 关键
- 可行性判断：最大计数 > (n+1)//2 则无解（间隔定理：n 个位置、最密摆放是隔一个放一个）
- 奇偶位填充：按频次降序遍历，下标每次 +2 先占偶数位；越过 n 后跳到 1 占奇数位
- 最高频字符计数 ≤ 偶数位个数（可行性条件保证），所以它独占偶数位时不会自相邻；后续字符填剩余位置也天然隔开

## 教训
- 看到"重构字符串使相邻字符不同" → 先判 max_count > (n+1)//2，再奇偶位填充
- 自己"贪心轮流取两个最大"失败的原因：aabbcc 填成 abab 后 c 无处可插——"轮流配对"对均频多字符会断裂；"先占偶数位"才是保证间隔的构造方法
