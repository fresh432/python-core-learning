# LeetCode 581 最短无序连续子数组

## 我的思路（55分钟）
- 前20分钟：双指针——从左到右找第一个需要交换的左边界、从右到左找右边界；但处理不了 [1,2,4,5,3] 这种前半有序但"隔着"无序的情况
- 中间25分钟：改单调栈——循环出栈直到大于栈顶；但 [1,3,5,2,4] 中 5 提前被弹出导致 4 合法的情况处理不了，维护弹出最大值又处理不了连续重复
- 看答案10分钟：正确双指针是——第一次发现与增长方向相反的元素时停止指针移动，把未走过那边直接判为打乱区域；找左边界时，左指针走到首个非递增处停住，取右侧区间的最小值，让左指针回走直到该最小值不小于左指针所指元素；右边界反方向同理（取左侧最大值向右扩）

## 代码
```python
class Solution:
    def findUnsortedSubarray(self, nums: list[int]) -> int:
        # 右边界：从右往左找到首个非递增位置，再用左侧最大值向右扩
        r = len(nums) - 1
        while r >= 1 and nums[r] >= nums[r - 1]:
            r -= 1
        if r == 0:
            return 0

        max_v = max(nums[:r])
        while r < len(nums) - 1 and max_v > nums[r + 1]:
            r += 1

        # 左边界：从左往右找到首个非递增位置，再用右侧最小值向左扩
        l = 0
        while l < len(nums) - 1 and nums[l] <= nums[l + 1]:
            l += 1

        min_v = min(nums[l:])
        while l > 0 and min_v < nums[l - 1]:
            l -= 1

        return r - l + 1
```

## 关键
- 双指针各走一遍找到"初步断点"，断点另一侧的元素随时可能插到这边来——所以要用另一侧的极值继续扩展边界
- 左边界：右段最小值 min_v，左指针回走直到 nums[l-1] ≤ min_v
- 右边界：左段最大值 max_v，右指针扩直到 max_v ≤ nums[r+1]
- 全程有序（r 一路减到 0）直接返回 0

## 教训
- 看到"最短无序子数组" → 双指针 + 极值回扩边界，不要用单调栈
- 自己双指针失败的原因：只想"相邻交换"，没想到断点右侧的最小值可能属于左边、左侧的最大值可能属于右边
