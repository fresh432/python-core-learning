## LeetCode 263 丑数

## 我的思路（10分钟）
- 分别循环整除三个质因子：以 n % 因子 == 0 为条件整除当前质因子，三个因子各循环一遍，最后结果为 1 则是丑数
- 看答案发现除 2 的循环可以优化成位运算：剩下的数若是 2 的幂则必然只含因子 2

## 代码
```python
class Solution:
    def isUgly(self, n: int) -> bool:
        if n <= 0:
            return False
        while n % 5 == 0:
            n //= 5
        while n % 3 == 0:
            n //= 3
        return n & (n - 1) == 0
```

## 关键
- 丑数定义：只含质因子 2、3、5 → 不断整除 5、3、2，剩下 1 即为丑数
- 优化：整除完 5 和 3 后，n & (n-1) == 0 直接判断剩余部分是否为 2 的幂（含 1 = 2⁰），省掉第三个循环
- n <= 0 特判（丑数必须是正整数）

## 教训
- 看到"判断丑数" → 循环整除 2、3、5，剩 1 即是
- 技巧串联：231 的 2 的幂判定在这里复用——整除完其他因子后，剩余因子是否为 2 的幂可以一步判定
