# LeetCode 377 组合总和 IV

## 我的思路（40分钟）
- 前10分钟：读完题想到回溯枚举所有方案，但直觉数据量大时会超时，决定用 DP
- 中间15分钟：试图写 DP 但状态转移方程没理清楚，不知道该怎么累加前面的状态
- 后15分钟：看答案发现本质和爬楼梯一模一样——dp[i] 由前面所有能一步到达 i 的状态累加而来

## 代码
```python
class Solution:
    def combinationSum4(self, nums: List[int], target: int) -> int:
        if not nums:
            return 0
        dp = [0] * (target + 1)
        dp[0] = 1  # 和为0有1种方式：什么都不选
        
        for i in range(1, target + 1):
            for num in nums:
                if i >= num:
                    dp[i] += dp[i - num]
        
        return dp[target]
```

## 关键
- 状态定义：dp[i] = 和为 i 的组合数（顺序不同算不同方案）
- 状态转移：dp[i] += dp[i - num]，遍历所有 num ∈ nums 且 num ≤ i
- 初始化：dp[0] = 1（空集是唯一种凑成 0 的方式）
- 循环顺序决定求排列还是组合：
  - 外层 target + 内层 nums → 排列数（顺序不同算不同，本题要求）
  - 外层 nums + 内层 target → 组合数（顺序不同算相同）

## 教训
- 看到"求方案数/组合数" + "无限选取" → 完全背包计数 DP
- 322（零钱兑换）vs 377（组合总和 IV） 的核心差异：

|        题目       | 目标        | 转移                         | 循环顺序          |     结果类型     |
| :-------------: | :-------- | :------------------------- | :------------ | :----------: |
|     322 零钱兑换    | **最少**硬币数 | `min(dp[i], dp[i-coin]+1)` | 外层硬币，内层金额     |   组合（顺序无关）   |
| **377 组合总和 IV** | **所有**方案数 | **`dp[i] += dp[i-num]`**   | **外层金额，内层硬币** | **排列（顺序有关）** |

- 和 70 题（爬楼梯）对比：爬楼梯是 nums = [1, 2] 的特殊情况，本题是泛化版
- 回溯思维转 DP：当数据范围大时（target 可达 1000），必须用 DP，O(target × n) 可过
