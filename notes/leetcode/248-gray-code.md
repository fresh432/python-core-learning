# LeetCode 89 格雷编码

## 我的思路（50分钟）
- 前30分钟：类似回溯——每次找当前数字的下一位，判断"只有一位不同"用先异或、再 x & (x-1) 判断是否等于 0（即异或结果是否为 2 的幂），用数组标记数字是否用过。结果超时：每次都要把所有数字比对一遍
- 中间15分钟：看答案——镜像对称法：后半部分的数字最高位为 1，前半部分最高位为 0，其余部分排序镜像对称。每次倒序遍历数组，所有元素最高位加 1 后追加到数组，重复 n 轮
- 还看了格雷公式：第 i 个格雷码 = i ^ (i >> 1)，但原理没完全看懂
- 后5分钟：两种方法各写一遍

## 代码（镜像法）
```python
class Solution:
    def grayCode(self, n: int) -> list[int]:
        ans = [0]
        head = 1
        for i in range(n):
            for j in range(len(ans) - 1, -1, -1):
                ans.append(head + ans[j])
            head <<= 1
        return ans
```

## 代码（公式法）
```python
class Solution:
    def grayCode(self, n: int) -> list[int]:
        return [i ^ (i >> 1) for i in range(2 ** n)]
```

## 关键
- 镜像法：每轮将现有 ans 倒序遍历，每个元素加上 head（当前最高位）后追加；head 每轮左移一位，重复 n 轮得到 2ⁿ 个格雷码
- 公式法：G(i) = i ^ (i >> 1)，相邻两个格雷码只有一位不同
- 格雷码核心性质：相邻两数只有一位不同（镜像法靠倒序保证这一点）

## 教训
- 看到"生成格雷码" → 镜像法（倒序 + 最高位）或公式 i ^ (i >> 1)
- 踩坑：回溯 + 全量比对是 O(4ⁿ) 必然超时；这类"有数学结构的序列生成题"先找规律（对称性），别急着回溯
