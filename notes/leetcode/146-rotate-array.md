# LeetCode 189 轮转数组

## 我的思路（35分钟）
- 前15分钟：用切片拼接法，在 n-k 处将数组切成两段后调换顺序拼接。踩坑：忘记原地修改数组需要用 nums[:] 切片赋值，调试花了时间
- 中间10分钟：看答案，了解三次反转法——先整体反转，再分别反转前 k 个和后 n-k 个
- 后10分钟：用三次反转法写了一遍

## 代码（切片拼接法）
```python
class Solution:
    def rotate(self, nums: List[int], k: int) -> None:
        n = len(nums)
        k %= n
        nums[:] = nums[n - k:] + nums[:n - k]
```

## 代码（三次反转法）
```python
class Solution:
    def rotate(self, nums: List[int], k: int) -> None:
        def reverse(i, j):
            while i < j:
                nums[i], nums[j] = nums[j], nums[i]
                i += 1
                j -= 1
        
        n = len(nums)
        k %= n
        reverse(0, n - 1)   # 整体反转
        reverse(0, k - 1)   # 前 k 个反转
        reverse(k, n - 1)   # 后 n-k 个反转
```

## 关键
- k %= n：处理 k 大于数组长度的情况
- 切片法：nums[n-k:] + nums[:n-k] 直接拼接，但额外空间 O(n)
- 三次反转法：
  1. 整体反转：[1,2,3,4,5,6,7] → [7,6,5,4,3,2,1]
  2. 前 k 反转：[5,6,7,4,3,2,1]
  3. 后 n-k 反转：[5,6,7,1,2,3,4]
- 原地修改：切片法必须用 nums[:] 赋值，否则只是重新绑定变量

## 教训
- 看到"数组轮转/右移 k 位" → 三次反转是 O(1) 空间的标准解法
- 原地修改数组：nums[:] = ... 是 Python 中修改原列表的惯用写法，nums = ... 只是重新赋值变量
- 切片法代码简洁但空间不优，面试时优先写三次反转法
