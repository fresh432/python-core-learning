# LeetCode 337 打家劫舍 III

## 我的思路（45分钟）
- 前15分钟：想通过只取奇数层或偶数层来比较最大值，但发现有些情况需要连续跳过某些节点，奇偶分层不成立
- 中间15分钟：思考如何保存"偷"和"不偷"两种状态，没想出合适的传递方式
- 后15分钟：看答案，了解到树形 DP 返回二元组——每个节点返回 (偷该节点的最大值, 不偷该节点的最大值)，然后动手实现

## 代码
```python
class Solution:
    def rob(self, root: Optional[TreeNode]) -> int:
        def func(R):
            if not R:
                return (0, 0)
            
            left, left1 = func(R.left)
            right, right1 = func(R.right)
            
            # 偷当前节点：子节点不能偷
            select = left1 + right1 + R.val
            # 不偷当前节点：子节点可偷可不偷，取各自最大值
            not_select = max(left, left1) + max(right, right1)
            
            return (select, not_select)
        
        return max(func(root))
```

## 关键
- 树形 DP：后序遍历，自底向上传递状态
- 返回二元组 (select, not_select)：
  - select：偷当前节点，则子节点必须不偷 → left1 + right1 + R.val
  - not_select：不偷当前节点，子节点可偷可不偷 → max(left, left1) + max(right, right1)
- 空节点返回 (0, 0)，作为递归边界
- 最终结果：max(func(root))（根节点可偷可不偷）

## 教训
- 看到"树形结构 + 相邻限制（父子不能同时选）" → 树形 DP，返回二元组
- 不要试图用层序或奇偶分层，树的结构不规则，必须用递归返回状态
- 二元组设计是树形 DP 的经典模式：dp[node] = (选当前, 不选当前)
- 和 198/213 题对比：
