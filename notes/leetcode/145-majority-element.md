# LeetCode 169 多数元素

## 我的思路（40分钟）
- 前15分钟：只想到了哈希表计数的方法，空间复杂度 O(n)
- 中间15分钟：看答案，了解到 Boyer-Moore 摩尔投票法——因为众数出现次数超过 n/2，即使把所有不同的元素两两配对抵消，最后剩下的必然是该众数
- 后5分钟：自己写出摩尔投票法
- 最后5分钟：顺便了解了排序取中值的解法（排序后 nums[n//2] 必为众数）

## 代码（摩尔投票法）
```python
class Solution:
    def majorityElement(self, nums: List[int]) -> int:
        votes = 0
        for num in nums:
            if votes == 0:
                x = num
            votes += 1 if x == num else -1
        return x
```

## 关键
- 摩尔投票法：维护一个候选元素 x 和票数 votes
- 遍历数组：若 votes == 0，当前元素成为新候选
- 相同元素 votes += 1，不同元素 votes -= 1
- 核心保证：众数出现次数 > n/2，即使最坏情况下与其他所有元素抵消，最终仍会胜出

## 教训
- 看到"出现次数超过一半" → 摩尔投票法，O(n) 时间 O(1) 空间
- 简单替代方案：排序后取中位数 nums[n // 2]，但时间 O(n log n)
- 摩尔投票法的本质：两两抵消，多数元素的"票数优势"保证最后存活
