# LeetCode 518 零钱兑换 II

## 我的思路（40分钟）
- 前10分钟：想到完全背包模板，dp[i] 保存金额 i 的方案数。思路正确：当 i < coin 时不操作
- 中间25分钟：想复杂了，以为状态转移需要 i % coin == 0 才进行累加，否则只取前一个值。边画图边调试始终不通过
- 后5分钟：看答案，发现状态转移方程极其简单——dp[i] += dp[i - coin]，不需要取模判断，直接累加即可

## 代码
```python
class Solution:
    def change(self, amount: int, coins: List[int]) -> int:
        dp = [0] * (amount + 1)
        dp[0] = 1
        
        for coin in coins:
            for i in range(1, amount + 1):
                if i < coin:
                    continue
                dp[i] += dp[i - coin]
        
        return dp[-1]
```

## 关键
- 完全背包求方案数：dp[i] 表示凑成金额 i 的方案数
- 状态转移：dp[i] += dp[i - coin]（注意是 += 不是 = min/max）
- 初始化：dp[0] = 1（凑成0元有1种方案：什么都不选）
- 遍历顺序：外层硬币，内层金额正序（完全背包，可重复取）

## 教训
- 看到"凑成金额的方案数" → 完全背包，dp[i] += dp[i - coin]
- 不要想复杂：不需要取模判断，不需要特殊条件，就是简单的累加
- 和 322 题对比：322 是完全背包求最值（最少硬币数，min），518 是完全背包求方案数（+=）
- 背包问题还是不熟练，需要继续加深
