# LeetCode 91 解码方法

## 我的思路（80分钟）
- 前20分钟：完全没思路，不知道数字字符串怎么拆分成合法字母
- 中间30分钟：意识到本质和爬楼梯类似——每个位置可以单独解码（爬1步）或和前一个组合解码（爬2步），但开始调试各种边界条件（'0' 怎么处理、前导零、大于26的情况），写得很啰嗦
- 后20分钟：看别人的代码，发现所有边界可以统一简化为两个判断：当前位是否为 '0'、两位组合是否在 [10, 26] 范围内
- 最后10分钟：重写优化版，代码简洁很多

## 代码（初版）
```python
class Solution:
    def numDecodings(self, s: str) -> int:
        n = len(s)
        dp = [0] * (n + 1)
        
        if s[0] != '0':
            dp[1] = 1
            if n >= 2 and int(s[:2]) <= 26:
                if s[1] == '0':
                    dp[2] = 1
                else:
                    dp[2] = 2
            elif n >= 2 and int(s[:2]) > 26:
                if s[1] == '0':
                    return 0
                dp[2] = 1
        
        for i in range(3, n + 1):
            if s[i - 1] == '0':
                if s[i - 2] == '0' or int(s[i - 2:i]) > 26:
                    return 0
                dp[i] = dp[i - 2]
            elif int(s[i - 2:i]) > 26 or s[i - 2] == '0':
                dp[i] = dp[i - 1]
            else:
                dp[i] = dp[i - 1] + dp[i - 2]
        
        return dp[-1]
```

## 代码（优化版）
```python
class Solution:
    def numDecodings(self, s: str) -> int:
        n = len(s)
        if s[0] == '0':
            return 0
        
        dp = [0] * (n + 1)
        dp[0] = 1  # 空串有1种解码方式
        dp[1] = 1  # 第一个字符非'0'，有1种
        
        for i in range(2, n + 1):
            # 单独解码当前位（当前位不是'0'）
            if s[i - 1] != '0':
                dp[i] += dp[i - 1]
            # 和前一位组合解码（组合在10~26之间）
            if 10 <= int(s[i - 2:i]) <= 26:
                dp[i] += dp[i - 2]
        
        return dp[-1]
```

## 关键
- 状态定义：dp[i] = 前 i 个字符的解码方案数
- 状态转移（两种独立选择，累加）：
  - 单独解码 s[i-1]：要求 s[i-1] != '0' → dp[i] += dp[i-1]
  - 组合解码 s[i-2:i]：要求 10 <= int(...) <= 26 → dp[i] += dp[i-2]
- 初始化：dp[0] = 1（空串算一种方案，作为递推基石），dp[1] = 1（首字符非 '0'）
- '0' 的特殊性：不能单独解码，只能作为 10 或 20 的一部分

## 教训
- 看到"数字字符串解码/拆分" → 爬楼梯约束版，dp[i] 由 dp[i-1] 和 dp[i-2] 转移
- 边界简化的核心：不要写复杂的 if-else 嵌套，统一判断两个条件即可
- dp[0] = 1 是计数类问题的常见初始化（空集/空串算一种合法方案）
- 和 70 题（爬楼梯）对比：爬楼梯是 dp[i] = dp[i-1] + dp[i-2] 无条件，91 题多了合法性约束（'0' 不能单独出现、两位不能大于26）
