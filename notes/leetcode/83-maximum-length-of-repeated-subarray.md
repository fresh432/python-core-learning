# LeetCode 718 最长重复子数组

## 我的思路（15分钟）
和 1143 题类似，花了7分钟写好框架，只是子数组要求连续，所以不相等时重置为0。调试时因为数组行列没分好，导致下标越界。

## 代码
```python
class Solution:
    def findLength(self, nums1: List[int], nums2: List[int]) -> int:
        n, m = len(nums1), len(nums2)
        dp = [[0] * (m + 1) for _ in range(n + 1)]
        l = 0
        
        for i in range(1, n + 1):
            for j in range(1, m + 1):
                if nums1[i - 1] == nums2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1] + 1
                    l = max(dp[i][j], l)
        
        return l
```

## 关键
- 状态定义：dp[i][j] = 以 nums1[i-1] 和 nums2[j-1] 结尾的最长重复子数组长度
- 状态转移：
  - 相等：dp[i][j] = dp[i-1][j-1] + 1（连续，继承左上角）
  - 不等：dp[i][j] = 0（不连续，重置）
- 全局维护最大值：l = max(l, dp[i][j])

## 和 1143 题的对比
| 题目              | 要求            | 不等时的处理      | dp 含义                |
| --------------- | ------------- | ----------- | -------------------- |
| 1143 LCS        | 子序列（可不连续）     | `max(左, 上)` | 前缀的最长公共子序列           |
| **718 最长重复子数组** | **子数组（必须连续）** | **`0`（重置）** | **以 i,j 结尾的最长重复子数组** |

## 教训
- 子序列 vs 子数组：子序列可以不连续，子数组必须连续——这是 DP 转移方程的核心区别
- 二维数组创建时注意行列：dp = [[0] * (m+1) for _ in range(n+1)]，外层是 n+1 行，内层是 m+1 列
- 看到"两个数组/字符串" + "最长公共" → 先判断是子序列还是子数组
