# LeetCode 300 最长递增子序列

## 我的思路（40分钟）
- 前10分钟：想到 DP，每个问题切分成最小子问题
- 中间10分钟：卡在内层循环——以为除了保存最长长度还要保存该状态的数值，然后和下一个比较，这样写感觉不像 DP
- 后20分钟：看答案理解——dp[i] 表示以 nums[i] 结尾的最长递增子序列长度

## 代码
```python
class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        if not nums:
            return 0
        n = len(nums)
        dp = [1] * n          # 每个元素自身就是一个长度为1的递增子序列
        
        for i in range(n):
            for j in range(i):
                if nums[j] < nums[i]:      # 前面有比当前小的
                    dp[i] = max(dp[i], dp[j] + 1)
        
        return max(dp)
```

## 关键
- 状态定义：dp[i] = 以 nums[i] 结尾的最长递增子序列长度
- 状态转移：dp[i] = max(dp[i], dp[j] + 1)，其中 j < i 且 nums[j] < nums[i]
- 内层循环：遍历 i 之前的所有元素，找比 nums[i] 小的，更新 dp[i]
- 最后返回 max(dp)，因为最长子序列不一定以最后一个元素结尾

## 教训
- dp[i] 的含义要明确：不是"前 i 个元素的最长递增子序列"，而是"以第 i 个元素结尾的最长递增子序列"
- 不需要额外保存"该状态的数值"，nums[i] 本身就是数值
- 看到"最长递增子序列" → O(n²) 的 DP，或者 O(n log n) 的二分+贪心（进阶）
- 和 322 题对比：

| 题目          | dp 含义              | 转移方式             |
| ----------- | ------------------ | ---------------- |
| 322 零钱兑换    | 凑成金额 i 的最少硬币       | 遍历硬币，取 min       |
| **300 LIS** | **以 i 结尾的最长递增子序列** | **遍历前面所有 j，找小的** |
