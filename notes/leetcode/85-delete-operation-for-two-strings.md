# LeetCode 583 两个字符串的删除操作

## 我的思路（20分钟）
1. 前5分钟：想到和 72 题解法类似
2. 中间5分钟：画矩阵观察规律
3. 后10分钟：写出来调试通过

## 代码
```python
class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        n1, n2 = len(word1), len(word2)
        dp = [[0] * (n2 + 1) for _ in range(n1 + 1)]
        
        for i in range(1, n1 + 1):
            dp[i][0] = dp[i-1][0] + 1
        for j in range(1, n2 + 1):
            dp[0][j] = dp[0][j-1] + 1
        
        for i in range(1, n1 + 1):
            for j in range(1, n2 + 1):
                if word1[i-1] == word2[j-1]:
                    dp[i][j] = dp[i-1][j-1]
                else:
                    dp[i][j] = min(dp[i-1][j], dp[i][j-1]) + 1
        
        return dp[n1][n2]
```

## 关键
- 状态定义：dp[i][j] = 使 word1[0:i] 和 word2[0:j] 相同的最小删除步数
- 状态转移：
  - 字符相等：dp[i][j] = dp[i-1][j-1]（不用删）
  - 字符不等：min(删word1[i-1], 删word2[j-1]) + 1
- 只有删除操作：没有插入和替换，所以不等时只比较左和上

## 和 72 题的对比
| 题目           | 允许操作    | 不等时的转移              |
| ------------ | ------- | ------------------- |
| 72 编辑距离      | 增删改     | `min(左, 上, 左上) + 1` |
| **583 删除操作** | **仅删除** | **`min(左, 上) + 1`** |

## 教训
- 583 题是 72 题的简化版——只有删除，没有插入和替换
- 画矩阵找规律是二维 DP 的标准流程，5分钟画图能省30分钟调试
- 看到"使两个字符串相同的最少操作" → 先判断允许哪些操作，再写转移方程
