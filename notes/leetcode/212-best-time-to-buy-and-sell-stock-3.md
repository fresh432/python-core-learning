# LeetCode 123 买卖股票的最佳时机 III

## 我的思路（75分钟）
- 前10分钟：想到用 DP 维护每天的不同状态（交易过/未交易 × 持有/未持有）
- 中间45分钟：状态转移方程卡住，调试始终不过。方向错误——用"是否交易过"作为维度，但实际应该用交易次数作为维度
- 后10分钟：看答案发现应该是定义为交易次数，状态定义为 dp[k][hold][i]：
  - k：交易次数（0, 1, 2）
  - hold：是否持有（0未持有, 1持有）
  - i：第几天
- 后10分钟：跟着答案写了一遍，通过

## 代码
```python
class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        n = len(prices)
        # dp[k][hold][i]: 第i天, 最多交易k次, hold表示是否持有
        dp = [[[0] * (n + 1) for _ in range(2)] for _ in range(3)]
        
        dp[0][1][0] = -prices[0]
        dp[1][1][0] = -prices[0]
        
        for i in range(1, n + 1):
            # 交易1次且未持有 = max(昨天就未持有, 昨天交易0次且持有今天卖)
            dp[1][0][i] = max(dp[1][0][i - 1], dp[0][1][i - 1] + prices[i - 1])
            # 交易2次且未持有 = max(昨天就未持有, 昨天交易1次且持有今天卖)
            dp[2][0][i] = max(dp[2][0][i - 1], dp[1][1][i - 1] + prices[i - 1])
            
            # 交易0次且持有 = max(今天买, 昨天就持有)
            dp[0][1][i] = max(-prices[i - 1], dp[0][1][i - 1])
            # 交易1次且持有 = max(今天买, 昨天就持有)
            dp[1][1][i] = max(dp[1][0][i] - prices[i - 1], dp[1][1][i - 1])
        
        return dp[2][0][-1]
```

## 关键
- 三维 DP：dp[k][hold][i]，k∈[0,2]，hold∈[0,1]
- 状态转移：
  - 未持有：dp[k][0][i] = max(保持未持有, dp[k-1][1][i-1] + prices[i-1]) — 昨天持有今天卖，交易次数+1
  - 持有：dp[k][1][i] = max(保持持有, dp[k][0][i] - prices[i-1]) — 今天买
- 答案：dp[2][0][-1]，最多交易2次且未持有的最大利润
