# LeetCode 442 数组中重复的数据

## 我的思路（15分钟）
- 前10分钟：以为是异或或字典树
- 后来突然想到应该在原数组上做标记
  - 数组内数字的取值范围是数组长度，所以遍历时把遍历到的数字作为下标，将对应下标位置的数字改成负数
  - 当发现对应下标位置的值已经是负数时，说明该数字已经出现过，加入 ans，全部遍历完后返回ans即可

## 代码
```python
class Solution:
    def findDuplicates(self, nums: List[int]) -> List[int]:
        ans = []
        for i in range(len(nums)):
            if nums[i] < 0:
                num = -nums[i]        # 还原被标记过的值
            else:
                num = nums[i]

            if nums[num - 1] < 0:     # 该位置已被标记，num 是第二次出现
                ans.append(num)
            else:
                nums[num - 1] = -nums[num - 1]   # 首次出现，标记
        return ans
```

## 关键
- 关键前提：数字取值范围是 [1, n]，下标范围是 [0, n-1]，所以 num 可以直接映射到 num - 1 的位置
- 用符号位做标记：取负 = "已访问"；遍历前先取绝对值还原当前数字
- 每个数字最多出现两次（题设），所以见到已标记位置就是答案

## 教训
- 看到"数组取值在 [1, n]、找重复元素" → 原地标记（下标映射 + 取负），O(n) 时间 O(1) 额外空间
- 自己前10分钟想异或/字典树是方向错误：异或只能处理"出现一次"的差值场景，找"哪些重复"要靠标记
