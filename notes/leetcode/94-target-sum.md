## 代码
```python
class Solution:
    def findTargetSumWays(self, nums: List[int], target: int) -> int:
        s = sum(nums)
        if (target + s) % 2:
            return 0
        if abs(target) > s:
            return 0
        x = (target + s) // 2
        dp = [1] + [0] * x
        
        for num in nums:
            for j in range(x, num - 1, -1):
                dp[j] += dp[j - num]
        
        return dp[-1]
```

## 关键
- 数学转换（核心）：设正数和为 P，负数和为 N，则
  - P - N = target
  - P + N = sum(nums)
  - 解得 P = (target + sum) // 2
  - 问题转化为：从 nums 中选若干个数，使其和为 P 的方案数
- 状态定义：dp[i] = 凑出和为 i 的方案数
- 状态转移：dp[j] += dp[j - num]（选当前数的所有方案累加）
- 初始化：dp[0] = 1（凑出 0 有 1 种方式：什么都不选）
- 边界条件：(target + s) 必须是偶数，且 abs(target) <= s

## 教训
- 看到"给数组元素加 ± 号使结果等于 target" → 数学转换转化为 0-1 背包计数问题
- 和 416 题对比：两题都是 0-1 背包 + 数学转换，核心差异在 dp 的类型和转移方式
