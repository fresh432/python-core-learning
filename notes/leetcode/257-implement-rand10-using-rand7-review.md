# LeetCode 470 用 Rand7 实现 Rand10（复习）

## 我的思路（2分钟）
- (rand7()-1)×7 模拟"进位"（0、7、14…42），加上 rand7()（1~7），得到 1~49 均分（每个概率 1/49）
- 目标是 1~10 均分：拒绝采样去掉 41~49，剩 40 个样本（10 的整数倍，每数概率 1/40）
- 对 10 取模再加一 → 1~10 各 1/10
- 优化方向：减少被拒绝元素的数量（接受率越高，期望调用次数越少）

## 代码
```python
class Solution:
    def rand10(self):
        while True:
            ans = (rand7() - 1) * 7 + rand7()
            if ans <= 40:
                return ans % 10 + 1
```

## 关键
- 这次能完整讲清均分原理了（上次"按直觉写的"）：49 种组合一一映射 → 截断到 40（10 的倍数）→ 取模均分
- 拒绝采样通用公式：(randX()-1)×X + randX() 生成 1~X²，截断到 Y 的最大倍数再取模
