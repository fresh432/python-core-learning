# LeetCode 477 汉明距离总和

## 我的思路（40分钟）
- 前25分钟：只想到两两异或的暴力枚举法
- 看提示：可以按位统计——每个 bit 位上 1 的个数单独计算，设某位置有 c 个 1，则该位置贡献 c × (n - c)（1 与 0 两两配对的数量）
- 花10分钟写出数组版（先存每个位置的 1 个数），又花5分钟优化：外层遍历 32 个 bit 位、内层遍历数字，每轮遍历完直接将该位的 c × (n - c) 累加进 ans，省掉存储数组

## 代码
```python
class Solution:
    def totalHammingDistance(self, nums: list[int]) -> int:
        ans = 0
        n = len(nums)
        for i in range(32):
            count = 0
            for num in nums:
                if (num >> i) & 1:
                    count += 1
            ans += count * (n - count)
        return ans
```

## 关键
- 按位统计贡献：第 i 位有 c 个 1、n - c 个 0，则该位对所有数对的总汉明距离贡献 c × (n - c)
- 时间复杂度 O(32n)，代替两两异或的 O(n²)
- 遍历方向：外层 bit 位、内层数字，可直接累加无需数组

## 教训
- 看到"所有数对的汉明距离总和" → 按位统计 c × (n - c)，不要两两枚举
- 和 461 题对比：461 是单对数的汉明距离（异或 + 计数），477 是多对总和（按位统计）——当两两组合很多时，先想"按维度拆贡献"而不是枚举对
- 踩坑记录：前25分钟卡在暴力枚举，说明对"贡献拆分"的套路还不够敏感
