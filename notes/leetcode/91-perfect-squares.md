# LeetCode 279 完全平方数

## 我的思路（40分钟）
- 前20分钟：本能想画二维数组，担心内存占用大，又试图把数字切分成字符串来构建状态表，逻辑越绕越复杂，最终放弃
- 后20分钟：看答案发现完全不需要二维——一维数组即可，dp[i] 直接表示和为 i 的最少完全平方数个数，豁然开朗后写出代码

## 代码
```python
class Solution:
    def numSquares(self, n: int) -> int:
        dp = [0] * (n + 1)
        for i in range(1, n + 1):
            dp[i] = i  # 最坏情况：i 个 1² 相加
            for j in range(1, n + 1):
                if i - j * j >= 0:
                    dp[i] = min(dp[i], dp[i - j * j] + 1)
                    continue
                break
        return dp[-1]
```

## 关键
- 状态定义：dp[i] = 和为 i 的最少完全平方数个数
- 状态转移：dp[i] = min(dp[i], dp[i - j²] + 1)，其中 j² ≤ i
- 初始化：dp[i] = i（最坏情况由 i 个 1² 组成），dp[0] = 0
- 本质：完全背包问题——每种平方数（1, 4, 9, 16...）可以无限使用，求凑成目标的最少个数

## 教训
- 看到"最少数量/最小个数" + "无限选取" → 一维完全背包 DP，不要想二维
- dp[i] = i 的初始化技巧：利用 1² 一定能凑成任意数，提供上界基准
- 内层循环 j 只需到 √i 即可，写成 range(1, int(i**0.5) + 1) 更简洁
- 和 322 题（零钱兑换）对比：两题都是完全背包求最值，只是 279 的"物品"是平方数，需要现场生成
